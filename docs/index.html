What is Sentinel Mesh?

Sentinel Mesh is a network of autonomous agents that monitors trending tokens and smart-money wallets on Base and Solana around the clock, executes guarded copy trades with hard spend caps and a durable onchain-grade journal, and exposes its market intelligence as a paid API using the x402 HTTP payment protocol: an agent (or trader) fetches /api/v1/…, receives 402 Payment Required, signs a USDC payment, and gets the data — machine commerce with no accounts and no keys to leak.
